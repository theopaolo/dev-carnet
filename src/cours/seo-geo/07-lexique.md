# Lexique

Les termes anglais sont ceux de la documentation et des outils.

| Terme | Sens | Chapitre |
| --- | --- | --- |
| 200 | Code de statut HTTP indiquant que la demande a réussi | [Réponses du serveur](/seo-geo/02-seo-technique/#comprendre-les-reponses-du-serveur) |
| 301, Redirection 301 | Réponse du serveur indiquant qu'une page a déménagé définitivement et donnant sa nouvelle adresse | [Changement d'adresse](/seo-geo/02-seo-technique/#une-page-change-dadresse--la-redirection-301) |
| 404 | Code de statut HTTP indiquant qu'aucune page n'a été trouvée à l'adresse demandée | [Page introuvable](/seo-geo/02-seo-technique/#une-page-est-introuvable--le-code-404) |
| `alt`, alternative textuelle | Texte qui transmet l'information d'une image aux personnes qui ne la voient pas. Une image décorative reçoit un alt vide | [Images](/seo-geo/02-seo-technique/#organiser-le-contenu-avec-des-balises-html) |
| Aperçu IA, Aperçus IA (*AI Overview*) | Réponse rédigée par IA dans Google, avec des liens vers des sources | [Résultats Google](/seo-geo/01-moteurs-de-recherche/#reconnaitre-les-elements-dune-page-de-resultats) |
| Backlink | Lien depuis un autre site vers le vôtre | [Liens entre sites](/seo-geo/03-contenu/#faire-connaitre-la-salle-sur-dautres-sites) |
| Canonical | Indication de l'adresse de référence lorsque le même contenu existe à plusieurs URL | [Le head](/seo-geo/02-seo-technique/#que-mettre-dans-le-head-dune-page) |
| Certificat TLS | Certificat numérique qui permet au navigateur de vérifier l'identité du serveur lors de l'établissement d'une connexion HTTPS | [HTTPS](/seo-geo/02-seo-technique/#securiser-la-connexion-avec-https) |
| Chargement différé, `loading="lazy"` | Chargement d'une image reporté jusqu'à ce qu'elle approche de la zone visible. Il évite de télécharger immédiatement les images situées plus bas dans la page | [Images sur mobile](/seo-geo/02-seo-technique/#rendre-les-pages-lisibles-et-rapides-a-charger-sur-mobile) |
| CLS (*Cumulative Layout Shift*) | Score qui mesure les déplacements inattendus des éléments pendant la consultation d'une page | [Stabilité visuelle](/seo-geo/02-seo-technique/#rendre-les-pages-lisibles-et-rapides-a-charger-sur-mobile) |
| Code de statut HTTP | Nombre envoyé par le serveur pour indiquer le résultat d'une demande, par exemple 200, 301 ou 404 | [Réponses du serveur](/seo-geo/02-seo-technique/#comprendre-les-reponses-du-serveur) |
| Conversion | Action que l'annonceur souhaite obtenir : réservation, inscription ou achat | [Page d'arrivée](/seo-geo/05-sea-et-gea/#preparer-la-page-vers-laquelle-mene-lannonce) |
| Core Web Vitals | Mesures de l'affichage (LCP), de la réactivité (INP) et de la stabilité visuelle (CLS) | [Mobile](/seo-geo/02-seo-technique/#rendre-les-pages-lisibles-et-rapides-a-charger-sur-mobile) |
| CPC, coût par clic | Coût par clic sur une annonce | [Annonces Google](/seo-geo/05-sea-et-gea/#reconnaitre-une-annonce-dans-google) |
| CSR, rendu côté client | Construction du contenu de la page par JavaScript dans le navigateur, après réception des fichiers du site | [Rendu HTML](/seo-geo/02-seo-technique/#verifier-ce-quun-robot-peut-lire-sans-javascript) |
| CTR, taux de clic | Taux de clic : clics divisés par impressions, exprimé en pourcentage | [Search Console](/seo-geo/03-contenu/#suivre-les-resultats-dans-search-console) |
| DevTools | Outils de développement intégrés au navigateur pour inspecter une page, son code et son chargement | [Inspection du HTML](/seo-geo/02-seo-technique/#verifier-ce-quun-robot-peut-lire-sans-javascript) |
| Données structurées | Informations d'une page, comme le nom et l'adresse d'un lieu, décrites avec des champs standardisés pour les moteurs | [JSON-LD](/seo-geo/02-seo-technique/#decrire-la-salle-avec-des-donnees-structurees) |
| Enchère | Montant qu'un annonceur propose pour participer à l'attribution d'un emplacement publicitaire. Ce montant ne suffit pas à déterminer l'affichage | [Annonces](/seo-geo/05-sea-et-gea/#reconnaitre-une-annonce-dans-google) |
| Entraînement | Phase pendant laquelle un modèle d'IA apprend des régularités à partir de données. Elle est distincte d'une recherche web effectuée pour répondre à une question | [Sources des IA](/seo-geo/04-geo/#comment-une-ia-trouve-ses-sources) |
| Exploration (*crawling*) | Visite et téléchargement de pages par un robot pour en lire le contenu. Une page explorée n'est pas forcément ajoutée à l'index | [Moteurs](/seo-geo/01-moteurs-de-recherche/#de-la-decouverte-dune-page-a-son-affichage) |
| Fiche d'établissement Google | Fiche d'un lieu avec adresse, horaires, photos et avis | [Visibilité locale](/seo-geo/03-contenu/#faire-connaitre-la-salle-sur-dautres-sites) |
| GEA | Publicité affichée avec les réponses d'une IA | [Publicité](/seo-geo/05-sea-et-gea/) |
| GEO | Travail sur un site pour qu'il puisse être cité dans les réponses des IA | [GEO](/seo-geo/04-geo/) |
| `Google-Extended` | Identifiant utilisé dans robots.txt pour contrôler certains usages des contenus par Gemini, sans modifier leur présence dans Google Search. Ce n'est pas un robot distinct | [Usages des contenus](/seo-geo/04-geo/#autoriser-la-recherche-sans-autoriser-lentrainement) |
| Googlebot | Robot qui explore les pages pour la recherche Google | [Moteurs de recherche](/seo-geo/01-moteurs-de-recherche/) |
| `GPTBot` | Robot d'OpenAI qui collecte des contenus pouvant servir à l'entraînement de ses modèles. Son autorisation se règle séparément de celle de la recherche dans ChatGPT | [Robots OpenAI](/seo-geo/04-geo/#autoriser-la-recherche-sans-autoriser-lentrainement) |
| `head` | Partie du document HTML qui contient les informations sur la page, comme son titre et sa meta description | [En-tête HTML](/seo-geo/02-seo-technique/#que-mettre-dans-le-head-dune-page) |
| HTML | Langage de balisage qui structure une page web : titres, paragraphes, liens et images | [Structure de la page](/seo-geo/02-seo-technique/#organiser-le-contenu-avec-des-balises-html) |
| HTTP | Protocole, c'est-à-dire ensemble de règles, utilisé par le navigateur et le serveur pour échanger des pages et d'autres ressources web | [Réponses du serveur](/seo-geo/02-seo-technique/#comprendre-les-reponses-du-serveur) |
| HTTPS | Version sécurisée de HTTP, qui chiffre les échanges entre le navigateur et le serveur | [Connexion sécurisée](/seo-geo/02-seo-technique/#securiser-la-connexion-avec-https) |
| Impression, impressions | Affichage d'un résultat ou d'une annonce | [Search Console](/seo-geo/03-contenu/#suivre-les-resultats-dans-search-console) |
| Index | Base dans laquelle un moteur de recherche conserve des informations sur les pages qu'il peut proposer dans ses résultats | [Moteurs](/seo-geo/01-moteurs-de-recherche/) |
| Indexation | Analyse d'une page et ajout d'informations sur son contenu à l'index d'un moteur. Elle ne garantit pas une place dans les résultats | [Moteurs](/seo-geo/01-moteurs-de-recherche/#de-la-decouverte-dune-page-a-son-affichage) |
| Injection de prompt | Instruction insérée dans un contenu pour tenter de détourner la réponse d'une IA qui le lit | [Limites du GEO](/seo-geo/04-geo/#aucune-citation-par-une-ia-nest-garantie) |
| INP (*Interaction to Next Paint*) | Indicateur du délai entre une interaction, comme un clic, et le prochain affichage de la page. Il sert à évaluer sa réactivité | [Réactivité](/seo-geo/02-seo-technique/#rendre-les-pages-lisibles-et-rapides-a-charger-sur-mobile) |
| Intention de recherche | Besoin derrière une recherche : comprendre, trouver, comparer ou réserver | [Contenu](/seo-geo/03-contenu/#comprendre-le-besoin-derriere-une-recherche) |
| JSON-LD | Format de données structurées placé dans une balise `script` | [Données structurées](/seo-geo/02-seo-technique/#decrire-la-salle-avec-des-donnees-structurees) |
| `lastmod` | Champ d'un sitemap qui indique la date de dernière modification du contenu d'une page | [Sitemap](/seo-geo/02-seo-technique/#aider-les-robots-a-trouver-les-pages-avec-un-sitemap) |
| LCP (*Largest Contentful Paint*) | Temps nécessaire pour afficher le plus grand élément de contenu visible au chargement, souvent une image ou un bloc de texte | [Chargement](/seo-geo/02-seo-technique/#rendre-les-pages-lisibles-et-rapides-a-charger-sur-mobile) |
| Lighthouse | Outil d'audit qui teste une page et signale des problèmes de performance, d'accessibilité et de SEO. Son score ne mesure pas le classement dans Google | [Audit](/seo-geo/02-seo-technique/#controler-une-page-avec-lighthouse-et-suivre-le-site-avec-search-console) |
| `llms.txt` | Proposition de fichier Markdown qui présente un site et ses ressources aux outils d'IA. Il ne remplace pas robots.txt et ne garantit aucune citation | [Limites du GEO](/seo-geo/04-geo/#aucune-citation-par-une-ia-nest-garantie) |
| Longue traîne | Ensemble des recherches peu fréquentes, souvent précises | [Mots des visiteurs](/seo-geo/03-contenu/#employer-les-mots-des-visiteurs) |
| Meta description | Résumé de la page que Google peut reprendre comme extrait | [Le head](/seo-geo/02-seo-technique/#que-mettre-dans-le-head-dune-page) |
| `meta keywords` | Ancienne balise destinée à lister des mots-clés sur une page. Google ne l'utilise pas pour classer les résultats | [Idées reçues](/seo-geo/01-moteurs-de-recherche/#quelques-idees-recues-sur-le-referencement) |
| Mode IA | Recherche Google sous forme de conversation, avec une réponse générée et des sources | [Réponses d'IA](/seo-geo/04-geo/) |
| `noindex` | Instruction demandant de ne pas indexer une page | [Robots](/seo-geo/02-seo-technique/#distinguer-robotstxt-et-noindex) |
| `OAI-SearchBot` | Robot d'OpenAI utilisé pour faire apparaître des sites dans les résultats de recherche de ChatGPT. Il a un rôle distinct de GPTBot | [Robots OpenAI](/seo-geo/04-geo/#autoriser-la-recherche-sans-autoriser-lentrainement) |
| Pack local | Bloc de résultats avec une carte et des fiches d'établissements | [Résultats Google](/seo-geo/01-moteurs-de-recherche/#reconnaitre-les-elements-dune-page-de-resultats) |
| Page d'arrivée (*landing page*) | Page ouverte après un clic sur une annonce | [Publicité](/seo-geo/05-sea-et-gea/#preparer-la-page-vers-laquelle-mene-lannonce) |
| Position moyenne | Dans Search Console, moyenne de la position du résultat le mieux placé du site pour chaque affichage pris en compte | [Mesures](/seo-geo/03-contenu/#suivre-les-resultats-dans-search-console) |
| RAG | Méthode qui associe la recherche d'informations et la rédaction d'une réponse par IA | [Sources des IA](/seo-geo/04-geo/#comment-une-ia-trouve-ses-sources) |
| Résultat enrichi, résultats enrichis | Résultat de recherche accompagné d'informations supplémentaires issues de données structurées, par exemple le temps de cuisson d'une recette. Cet affichage n'est pas garanti | [Données structurées](/seo-geo/02-seo-technique/#decrire-la-salle-avec-des-donnees-structurees) |
| Résultat naturel | Résultat qu'un moteur sélectionne et classe sans que le site paie pour cet emplacement | [Résultats Google](/seo-geo/01-moteurs-de-recherche/#reconnaitre-les-elements-dune-page-de-resultats) |
| Robot, *crawler* | Programme qui visite et télécharge des pages web | [Moteurs de recherche](/seo-geo/01-moteurs-de-recherche/) |
| `robots.txt` | Fichier qui indique aux robots quelles adresses ils peuvent explorer | [Robots](/seo-geo/02-seo-technique/#distinguer-robotstxt-et-noindex) |
| SEA | Publicité dans les moteurs de recherche | [Publicité](/seo-geo/05-sea-et-gea/) |
| Search Console | Outil de Google pour suivre l'indexation, les recherches et les clics d'un site | [Outils](/seo-geo/02-seo-technique/#controler-une-page-avec-lighthouse-et-suivre-le-site-avec-search-console) |
| SEO | Référencement naturel dans les moteurs de recherche | [Présentation](/seo-geo/) |
| SERP | Page de résultats d'un moteur de recherche | [Résultats Google](/seo-geo/01-moteurs-de-recherche/#reconnaitre-les-elements-dune-page-de-resultats) |
| Sitemap, sitemaps | Fichier XML qui liste les adresses des pages à faire découvrir | [Sitemap](/seo-geo/02-seo-technique/#aider-les-robots-a-trouver-les-pages-avec-un-sitemap) |
| SSG, génération statique | Production des pages HTML lors de la construction du site. Ces fichiers sont ensuite envoyés aux visiteurs | [Rendu HTML](/seo-geo/02-seo-technique/#verifier-ce-quun-robot-peut-lire-sans-javascript) |
| SSR, rendu côté serveur | Production du HTML d'une page par le serveur en réponse à une demande, avant son envoi au navigateur | [Rendu HTML](/seo-geo/02-seo-technique/#verifier-ce-quun-robot-peut-lire-sans-javascript) |
| `title` | Balise qui donne le titre de la page, visible notamment dans l'onglet du navigateur. Un moteur peut le reprendre dans ses résultats | [Titre de page](/seo-geo/02-seo-technique/#que-mettre-dans-le-head-dune-page) |
| Traceur publicitaire, traceurs publicitaires | Mécanisme, par exemple un cookie ou un pixel, utilisé pour suivre des visites ou des actions à des fins publicitaires | [Mesure des conversions](/seo-geo/05-sea-et-gea/#preparer-la-page-vers-laquelle-mene-lannonce) |
| URL | Adresse d'une ressource sur le web, comme une page, une image ou un fichier | [Adresses](/seo-geo/02-seo-technique/#choisir-des-adresses-lisibles) |
| `viewport` | Zone dans laquelle le navigateur affiche la page. La balise meta viewport permet notamment d'adapter sa largeur à celle du téléphone | [Affichage mobile](/seo-geo/02-seo-technique/#que-mettre-dans-le-head-dune-page) |
| XML | Format de texte qui organise des données avec des balises. Les sitemaps l'utilisent pour lister les adresses des pages | [Sitemap](/seo-geo/02-seo-technique/#aider-les-robots-a-trouver-les-pages-avec-un-sitemap) |
