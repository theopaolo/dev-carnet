# Catégories des variables

Le framework de **Jorma Sajaniemi** est un vocabulaire qui aide à comprendre le **_rôle_** d'une variable avant de la renommer.

| Rôle | Ce qu'elle fait |
| --- | --- |
| Fixed value | ne change pas après initialisation |
| Stepper | parcourt une liste de valeurs (`i` dans un for) |
| Flag | indique qu'un état est vrai ou faux |
| Walker | traverse une structure de données |
| Most-recent holder | retient la dernière valeur rencontrée |
| Most-wanted holder | retient la meilleure valeur trouvée |
| Gatherer | accumule et agrège des données |
| Container | contient plusieurs éléments |
| Follower | garde trace d'une valeur précédente |
| Organizer | stocke une version réorganisée des données (triée, inversée) |
| Temporary | garde une valeur le temps d’une opération |
