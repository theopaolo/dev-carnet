## Schémas du cours

Les SVG sont générés depuis les fichiers Mermaid voisins, ou depuis reservations.mcd pour le MCD. Les formes et textes expliquent le cas pédagogique. Les méthodes utilisées sont attribuées dans les chapitres : Diátaxis, C4, Merise et Example Mapping.

Le graphe dependances.svg provient des imports réels du kit, extraits avec dependency-cruiser. Les vues C4 et la séquence décrivent une application fictive plus large. Le diagramme adr-annulation conserve l’état retenu par l’ADR 001.

Pour modifier une illustration, éditer sa source textuelle puis suivre les commandes du [kit](/documentation/10-demonstration/). Conserver ensemble le texte modifiable et le rendu que les lecteurs peuvent ouvrir.
